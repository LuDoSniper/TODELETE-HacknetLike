# Installation

Node.js 22+ recommandé.

```sh
npm install
npm run setup
npm run dev
```

Ouvrir http://localhost:5173. Pour la version compilée : `npm run build` puis `npm start` (port 3000).

Le jeu est une simulation entièrement fictive, sans connexion à des machines externes. Pour préserver la surprise, ne lisez pas les sources avant de jouer.
